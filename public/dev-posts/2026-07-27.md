## Seasonal Server Support

> The seasonal toggle is disabled for now. I've finished testing all the automated data collection and storage processes, and everything is ready to start collecting data on August 7.

The app now supports both **Classic** and **Seasonal** servers.

- **Server toggle** in the navigation bar — switch between Classic and Seasonal.
- **Dual data sources** — the app loads data from the selected server's database and official pages.
- **Refresh data** — from all sections (highscores, online activity, deaths...) automatically brings server's data when you switch.
- **External links** — All official Dura links points to the selected server's homepage.

## Deaths Section

A brand-new section dedicated to tracking deaths across the server.

- **Death log** with filterable list — browse all deaths for the selected period with PvP/PvE toggle.
- **Stat cards** showing Total Deaths, PvP/PvE Top Killer.
- **Charts, charts, charts !** — deaths per day timeline, top PvP killers, top PvE killers, and PvP vs PvE distribution.

Data is collected daily from the official Dura character pages and available for Day, Week, Month, Year, and All-time periods.
